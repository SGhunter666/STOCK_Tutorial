## 两种运行方式

### 方式一：单文件离线版（不需要服务器）

直接双击打开：

```text
dist/stock-market-academy-offline.html
```

CSS、JavaScript、中英语言包全部内联，`file://` 下即可运行；进度使用浏览器的 localStorage 保存。推荐使用 Chrome / Edge / Firefox。如果浏览器禁止 `file://` 存储，游戏仍可运行，但会提示进度无法保存。

代码更新后重新生成：

```bash
cd STOCKS
python3 tools/build-offline.py
```

### 方式二：开发版（需要本地服务器）

ES Modules 与 JSON 语言文件无法通过 `file://` 加载，因此开发版需要 HTTP：

```bash
cd STOCKS
python3 -m http.server 8000
```

打开：

- 游戏：<http://localhost:8000/>
- 核心与语言测试：<http://localhost:8000/tests/>

也可以使用任意静态服务器。请确认地址是 `http://`，不要双击 `index.html`。

## 模拟交易所（Phase 1–6）

`/exchange` 是与旧 8 tick 教学市场完全隔离的第二个模拟市场，用来先把「能正确交易的市场」做可靠：

- **50 家规范虚构公司**：20 家参考现实行业结构、30 家完全原创；4 位唯一代码，含财务、估值、股息、持股结构与风险字段；旧 40 家公司仍保留在学院市场。
- **独立时钟**：默认暂停，支持继续 / 暂停、1× / 5× / 10× / 30× / 60×、单步 1 秒、单步 1 分钟与推进 1 个完整交易日；每个交易日 390 分钟（09:30–16:00）。
- **行情**：成交事件更新 1 分钟 OHLCV，再聚合为 1m / 5m / 15m / 30m / 1h / 4h / 1D / 1W / 1M；当前未完成桶标记 `partial`，缺失分钟不补成交量。
- **季度财报**：50 家公司按季度生成三张财务报表（利润表 / 资产负债表 / 现金流），保持资产 = 负债 + 权益与现金流勾稽；财报在发布日才进入页面，并产生确定性的盈利意外与价格跳变。
- **完整三表明细**：公司资料卡可进入 `/exchange/statements/<ticker>` 明细页，按季度查看利润表、资产负债表、现金流量表与关键比率的全部行项目。
- **新闻系统**：每个交易日生成确定性的公司 / 板块 / 全市场新闻，按情绪与公司 beta 传导到价格；板块新闻还会按行业关联度外溢到相邻板块。新闻只显示已发布内容，不读取未来信息。
- **宏观经济**：政策利率、通胀、失业率、GDP、信贷、消费者信心、能源价格与风险偏好缓慢变化；每 21 个交易日发布一次数据，按公布值与预期的意外通过利率 / 增长 / 能源 / 风险渠道传导到不同板块，并形成正常、牛市、熊市、高波动、危机、流动性紧张、行业泡沫、衰退与复苏等市场状态。宏观不会回溯重写已经发布的财报，而是通过估值、业绩指引与盈利预期渠道影响市场。
- **行业相关性**：11 个板块拥有可解释的增长 / 利率 / 能源敏感度；科技与通信、金融与房地产、能源与材料等板块存在关联。相同宏观冲击下板块反应不同，新闻冲击会外溢，但不会所有股票同涨同跌。
- **业绩指引**：公司会在季度中途发布 EPS 指引，影响下一次财报的“市场预期”，并在发布指引时产生价格反应；后续财报的实际值与指引预期不一致时，会形成可追溯的盈利意外。
- **分红与拆股**：季度分红按持仓派发现金并调整除息价格；计划拆股按比例调整持仓数量 / 成本与公司价格。拆股会取消该股票的活动订单并记录公司事件，所有变动同步写入账户与存档。反向拆股会把零股按拆股后价格折算为现金补偿，避免出现不可交易的小数股。
- **回购与增发**：季度第 20 个交易日按固定计划执行股份回购或增发。回购使用公司现金、减少流通股并支持 EPS；增发新股、募集现金但稀释 EPS。后续季度报表的股数、现金、总资产、股东权益、融资现金流与每股指标同步调整，已发布的历史季度不会被回溯篡改。
- **并购与分拆**：季度第 45 个交易日执行。并购以现金 + 债务收购私人业务，动作季度起并入收入、利息与资产 / 负债；分拆 / 剥离出售部分业务，公司报表减少对应收入与资产，现有股东按持仓获得特别现金分配。
- **停牌**：计划停牌会取消该股票全部活动订单、冻结报价并阻止新订单与模拟交易；停牌期结束后自动恢复交易。
- **供股**：按持仓比例向现有股东开放认购，认购价通常低于市价；玩家可在截止日前参与或放弃，未使用权利到期失效。公司总股本与认购款同步计入后续报表。
- **破产 / 退市**：触发后取消订单、核销玩家持仓、把报价写至接近零并禁止交易；持仓成本计入已实现亏损，事件与损失写入公司事件卡和存档。
- **公司资料**：/exchange 显示公司阶段、风险、市值、PE、股息率、宏观敏感度、最新财报指标与最近四个季度历史。
- **订单簿**：做市商多档 bid / ask、玩家限价挂单、价格优先撮合、大单跨档吃深度与部分成交；订单状态为 pending / open / partiallyFilled / filled / cancelled / rejected。
- **账本**：现金、持仓、平均成本、已实现盈亏、费用与逐笔成交记录；买入预留现金、卖出预留持股，市价单剩余取消、限价单剩余挂单；暂停时提交的订单先进入待激活队列，下一个模拟秒才参与撮合。
- **融资融券与卖空**：账户支持融资买入、卖空与买入平空。开仓按 50% 初始保证金校验，多头维持保证金 25%、空头 30%；融资借款按 6.5% 年利率、借券按 3% 年费率逐交易日计提。维持保证金不足会生成追缴通知，次日仍未补足或权益为负时自动撤销挂单并按市值由大到小强制平仓；空头需支付分红、随拆股调整数量与成本、在破产退市时按 0.01 买回。所有保证金、空头与强平记录进入同一账户、成交账本与存档。
- **ETF**：新增 4 只可交易 ETF（MKT / TECH / DIV / SMAL），每只跟踪一组 50 家公司中的加权篮子。ETF 报价按成分股净值重估，在同一个订单簿中买卖，资料卡显示净值、溢折价、管理费率、成分权重与涨幅贡献。成分股发生拆股时按复权价格计算净值，避免 ETF 被错误减半。
- **期权**：同一交易所内提供欧式看涨 / 看跌期权，按 7 / 30 / 90 个交易日生成 5 档行权价。报价使用 Black-Scholes 与波动率微笑，支持买入、卖出、平仓、到期手动行权与自动交割；买入占用现金，卖出按覆盖规则占用保证金，未被股票或反向期权覆盖的空头按 20% 名义本金 / 行权价计担保。到期日按内在价值自动行权 / 指派并交割股票，资金或持股不足时回退为现金结算。默认欧式结算；可切换美式模式：深度实值（≥5%）空头在剩余 ≤3 个交易日时会在下一交易日开盘被确定性提前指派，权利金仍按欧式 Black-Scholes 近似定价。
- **公司债**：新增 6 只与虚构发行人关联的公司债，按政策利率曲线 + 信用利差定价，提供买卖价、到期收益率、票息、评级与持仓。债券使用现金交易，每 63 个交易日支付一次季度票息并直接入账；报价、票息与持仓同步进入账户权益和保证金快照。
- **高级订单**：在主订单簿之外提供止损、止损限价、追踪止损与 OCO 离场。条件单只在触发价被触及时才转为市价或限价执行；追踪止损随最高 / 最低价单向收紧；OCO 的止盈腿与止损腿共享同一批持股或借券，任一成交或取消时另一条自动撤销。
- **挑战模式**：3 个可选挑战（稳健冲刺 / 对冲进阶 / 长线耐力），各自限定交易日、目标收益、最大回撤、单只权重上限与可用品种 / 方向 / 融资。挑战直接使用当前账户，不重置资金；到期或回撤超限时结算并给出评分与 A–D 评级，同时显示权益曲线与逐日收益 / 回撤明细。挑战结算、保证金追缴与强制平仓会即时弹出提示。
- **时间旅行复盘**：每个交易日开盘保存一份紧凑快照（价格、账户、挑战、宏观与 RNG），保留最近 20 个交易日。可选择任意快照回到当日开盘重新推演；回退会丢弃该日之后的成交与订单，并记录为新的复盘分支。卡片同时用权益曲线展示已保存交易日的净值变化。
- **交易统计与归因**：交易所页新增复盘卡，汇总总权益、累计收益率、已实现 / 未实现盈亏、胜率、盈亏比、最大回撤与已平仓笔数；同时列出累计手续费、融资与借券成本、股息与票息，并按标的展示已实现 / 未实现盈亏归因。统计只读取已记录成交与当前持仓，不修改账户。
- **期权实物交割**：到期日按内在价值自动行权 / 指派并交割股票：多头看涨按行权价买入、多头看跌卖出，空头则交付或接收股票；现金不足或持股不足时回退为现金结算。到期日当天也可手动行权。
- **确定性与存档**：同种子 + 同指令序列得到相同状态；`sma.sim-exchange-v1` 保存模拟时间、日索引、序列、账户、订单、财报、新闻、公司行为、空头、保证金追缴与强平记录、ETF 持仓、期权合约与到期结算、债券与票息记录、挑战与时间线快照，恢复时重建订单簿与 ETF 净值。

## 操作指南

- **市场时钟**（顶部）：暂停 / 继续、1× / 5× / 20× 速度、快进到下一交易日。暂停时行情冻结，订单不会撮合。
- **模拟交易所**（侧栏 Simulated Exchange）：独立于学院市场与历史实验室。默认暂停，可继续 / 暂停、切换 1×–60×、单步 1 秒、单步 1 分钟或推进 1 个完整交易日；选择 50 家公司之一，查看 1m–1M K 线、订单簿与账户；可提交市价 / 限价 / 止损 / 止损限价 / 追踪止损与 OCO 订单，查看保证金状态、空头持仓、追缴与强平记录；同一页面还可选择 4 只 ETF、交易 7 / 30 / 90 天期权、买卖 6 只公司债、参加评分挑战，并用时间旅行回退到任一交易日开盘重新推演。所有产品共用同一现金账户、权益与存档，并用「保存」写入浏览器本地存档。
- **公司资料与财报**：模拟交易所的公司资料卡显示阶段、风险、市值、PE、股息率、最新已发布季度财报与最近四个季度历史。财报按季度发布，发布日会按盈利意外产生确定性的价格跳变；分红在季度除息日按持仓现金入账并下调报价，拆股会按比例调整持仓与成本、取消该股票的活动订单并记录公司事件。
- **完整三表与新闻**：公司资料卡可进入完整三表明细页，按季度查看利润表、资产负债表、现金流量表和关键比率；交易所侧栏的新闻卡显示当日公司 / 板块 / 全市场模拟新闻、影响幅度和发布日期，新闻会传导到价格，但不会提前显示未来事件。
- **宏观与行业**：交易所侧栏的宏观卡显示政策利率、通胀、失业率、GDP、信贷、风险偏好、能源价格与消费者信心，以及当前市场状态、下一数据日和最近一次实际值 / 预期值 / 意外；公司资料卡还会显示该板块的增长 / 利率 / 能源敏感度。宏观冲击会按板块差异传导，板块新闻会外溢到相关行业。
- **业绩指引**：公司会在季度中途发布 EPS 指引，公司事件卡显示季度、指引值与基准值；下一次财报会用该指引作为预期，实际 EPS 与指引的差异形成盈利意外。
- **回购与增发事件**：公司事件卡会显示回购 / 增发的比例、涉及股数与现金金额；公司资料卡同步显示当前流通股数，后续财报的每股指标会反映最新股数。
- **并购、分拆与停牌**：公司事件卡显示并购交易金额与并入收入比例、分拆/剥离比例与每股特别分配、停牌起止日期；停牌期间报价冻结，提交订单会提示“该股票正在停牌”。反向拆股会在事件卡显示拆股比例与零股现金补偿。
- **供股与破产退市**：供股卡显示认购比例、认购价、可认购股数、认购金额与截止日，可在截止前选择“参与供股”或“放弃供股”；破产退市会核销持仓、记录已实现亏损，并在报价卡显示“已退市”、拒绝新订单。
- **语言**：右上角按钮即时切换 `中文 ⇄ EN`，金额始终为虚拟美元，不做货币换算。
- **职业模式**：Career 页面显示当前职级、下一职级条件、薪资倒计时与职业收入。晋升条件直接读取课程、交易、实验、挑战、分支、权益、XP、投资报告与绩效评价，满足后点击晋升；薪资每 21 个交易日自动到账。晋升到独立交易员后可接取研究任务，填写观点、信心、目标价与摘要提交报告；评分达到 60 分才计入职业进度，并在每 21 个交易日获得一次绩效评价。
- **学习流程**：Academy → 单元 → 章节。点击「标记已学完并继续」才会记录进度；测验达到 80% 通过。已有基础可使用「跳级测试」（达到 90% 跳过课程与实战任务）。
- **实战任务**：系统直接检查模拟账户中的真实操作（例如买入金额、限价单成交、查看两家公司市值），没有「直接完成任务」按钮。
- **板块解锁**：完成单元的全部要求（阅读、实战、测验）后自动解锁对应板块，并提示新增可交易公司。
- **交易**：Market → 选择公司 → Trading 页面下单。默认每笔成交收取 $1.00 虚拟佣金；买入手续费计入持仓成本，卖出时按平均成本计算已实现盈亏。价格图表可在「日 K」与「分时」之间切换；分时显示当前交易日每个 tick 的模拟蜡烛。
- **实时行情通道**：Settings → 实时数据通道，填入允许 CORS 的 JSON 行情 URL 和刷新间隔后，Market 页会显示外部参考报价。该数据不会改变模拟价格或账户；留空则完全离线运行。
- **做空与保证金**：完成 Unit 17 第一节后解锁「做空 / 平空」，卖空需 50% 抵押；完成 Unit 18 第一节后解锁融资买入（最多 1.5:1 杠杆），融资余额按 8% 年利率每日计息，权益低于维持保证金会被强制平仓。
- **止损 / 追踪止损 / 止损限价 / OCO**：完成 Unit 19 第一节后解锁。止损单在触发价被触及后转为市价单，追踪止损会随有利价格收紧；止损限价单触发后只在限价或更优价格成交，OCO 同时挂出止盈与止损、一腿成交另一腿自动取消。触发后成交价可能滑点。
- **订单簿**：进阶布局在 Unit 20 第一节后显示五档深度与当前数量的滑点估算。
- **期权**：完成 Unit 21 第一节后解锁。期权页提供 30 / 60 / 90 天、7 档行权价的 Call / Put 链，按 Black-Scholes 定价；可买入、卖出开仓、按模型价值平仓，或持有至到期现金结算。
- **期权策略**：Unit 25 起可切换「卖出开仓」；策略卡片可一键构建 Covered Call、Cash-Secured Put、Bull Call / Bear Put Spread、Long Straddle / Long Strangle，并按担保 / 净支出校验后原子成交。
- **期货**：完成 Unit 29 第一节后解锁。期货页提供 30 / 60 / 90 天单只股票期货，15% 保证金；每日收盘按浮动盈亏进行盯市，到期按现货价格现金结算。
- **基金经营**：职业等级 5 后进入 Fund 页成立基金，选择策略、风险偏好、初始 AUM、业绩基准、业绩门槛与是否启用杠杆。基金用独立账户与客户份额运行：在交易区按单位净值买卖标的，客户申购会增加份额与现金、赎回会减少份额并支付现金；每 21 个交易日计提管理费与「高水位 + 门槛」业绩报酬，每 30 个交易日可能出现新客户。可招聘 / 解雇员工来获得研究观点、降低交易费用、加快信任度增长或由合规官降低清盘风险，并随时把管理公司现金提现。单票仓位、现金 / 杠杆下限、客户预期收益、运营成本、关键人员稳定性与 40% 回撤都会影响风控与清盘；策略计划区可生成再平衡建议，开启自动再平衡后会按间隔在日终执行；参数研究下方可运行组合优化器（最小方差 / 风险平价 / 均值方差），把目标权重转换为再平衡计划；收益归因展示逐持仓贡献和因子暴露。清盘后可重新成立基金。
- **宏观世界**：完成 Unit 13 后进入 Macro World，查看利率、通胀、增长、失业、收益率曲线、信用利差、消费者信心、经济日历与全球市场联动。宏观周期会通过小幅漂移影响模拟市场收益率，但所有数值仍由种子与交易日确定。
- **多资产交易**：完成 Unit 13 后进入 Multi-asset，按当前宏观曲线买卖债券、外汇、商品与加密资产。债券价格随收益率反向变动，季度票息自动入账；外汇以美元计价并在日终按新汇率重估；商品由实际利率、增长与风险偏好定价；加密资产支持小数单位与更高波动。四类资产都使用同一个现金账户与权益计算。
- **量化实验室**：完成 Unit 16 后进入 Quant Lab，选择标的、策略、参数、初始资金与佣金运行回测。结果不会改变模拟账户；策略信号在收盘确认、下一开盘成交，并输出收益、回撤、夏普、胜率、持仓时间、买入持有对照、权益曲线与交易记录。参数优化、多因子回归、ML 选股（逻辑回归 / MLP / 双隐层网络，可自动调参）与九类因子研究（含分析师修正与盘中资金流）同样可用。
- **基金参数研究**：基金策略计划下方可运行参数研究，用 100 组仓位 / 现金 / 间隔组合做样本内选优与样本外验证；结果表会标出最优配置、当前配置与过拟合风险，点击「应用最优仓位参数」会把持仓数、现金缓冲与间隔写回计划。
- **组合优化器**：在同一基金页选择最小方差 / 风险平价 / 均值方差、协方差窗口、单票上限与现金缓冲，运行后查看目标权重、年化收益与波动；点击「生成优化再平衡计划」会在策略计划区生成买卖建议，执行时仍走基金风控。
- **多因子风险与成本**：基金页的风险模型卡展示因子暴露、因子 / 特异性风险贡献和压力情景；策略计划会显示预计佣金、价差、冲击、征费与资本利得税，并按冲击调整下单数量与执行滑点。
- **基金税制**：成立基金时可选择不征税、15% 资本利得税或 25% + 0.1% 征费的教学档案；买入征费计入成本基础，卖出正收益扣资本利得税与征费，运营页显示累计税费。
- **Beginner / Advanced**：新手布局隐藏详细财务数据并显示解释；高级布局显示价差、预留现金、P/E、EPS 等资料。
- **存档**：自动保存；设置页可立即保存、导出 / 导入 JSON 存档、重置进度。

## 关键规则

- 市值 = 股价 × 总股本；收益率 = 盈亏 ÷ 投入成本 × 100%。
- 买入：现金减少（成交金额 + 佣金），成本基础包含佣金。
- 卖出：现金增加（成交金额 − 佣金），已实现盈亏 = 净收入 − 对应成本。
- 市价买 / 卖分别以卖价 / 买价成交；限价单只在价格达到或优于限价时成交，未成交资金 / 股份会被预留。
- 期权、做空、保证金与期货均使用独立的模拟引擎；保证金规则、现金结算与提前指派边界在各自页面和 `/boundaries` 中说明，不连接真实交易所。

## 浏览器要求

现代 Chrome / Edge / Safari / Firefox：Canvas、`Intl`、localStorage。开发版还需要 ES Modules 与 IndexedDB。离线版在浏览器允许 `file://` 存储时可以保存进度。
