# Stock Market Academy · 股票市场学院

中英双语金融市场教学与股票交易模拟游戏。**Phase 1–8 已全部完成（Unit 1–32），并加入 5 只可交易 ETF、6 个专业分支课程、Sandbox / Challenge 模式、8 级职业模式、基金经营、量化实验室与明确的模拟边界**：从「什么是股票」开始，依次学习交易、盈亏、股息、ETF、复利、K 线与技术分析、基本面、估值、宏观、组合、风险、策略、做空、保证金、止损与订单簿，再到期权基础、定价与 Greeks、卖出期权与多腿策略，最后完成期货、对冲、系统性风险与毕业挑战。

> 所有公司、价格、财报与新闻均为虚构。虚拟资金仅用于教学，不构成投资建议，也不代表任何正式金融职业资格。

## 两种运行方式

### 方式一：单文件离线版（不需要服务器）

直接双击打开：

```text
dist/stock-market-academy-offline.html
```

CSS、JavaScript、中英语言包全部内联，`file://` 下即可运行；进度使用浏览器的 localStorage 保存。推荐使用 Chrome / Edge / Firefox。如果浏览器禁止 `file://` 存储，游戏仍可运行，但会提示进度无法保存。

代码更新后重新生成：

```bash
cd STOCKS
python3 tools/build-offline.py
```

### 方式二：开发版（需要本地服务器）

ES Modules 与 JSON 语言文件无法通过 `file://` 加载，因此开发版需要 HTTP：

```bash
cd STOCKS
python3 -m http.server 8000
```

打开：

- 游戏：<http://localhost:8000/>
- 核心与语言测试：<http://localhost:8000/tests/>

也可以使用任意静态服务器。请确认地址是 `http://`，不要双击 `index.html`。

## 市场与解锁

交易所共 **40 家虚构公司 + 5 只可交易 ETF**，分为 6 个板块，随课程进度逐单元开放：

| 板块 | 数量 | 解锁条件 |
| --- | --- | --- |
| 核心市场 Core market | 8 家公司 | 默认开放 |
| 成长与创新 Growth & innovation | 8 家公司 | 完成第 1 单元 |
| 消费与医疗 Consumer & healthcare | 8 家公司 | 完成第 2 单元 |
| 金融与工业 Finance & industry | 8 家公司 | 完成第 3 单元 |
| 能源与前沿 Energy & frontier | 8 家公司 | 完成第 4 单元 |
| 可交易 ETF Tradable ETFs | 5 只 ETF | 完成第 7 单元 |

ETF（MKT / TECH / DIV / SMAL / DEF）有真实可交易的模拟报价：价格由成分股加权篮子派生，可买入、卖出与做空；交易页显示费用率、成分数量、模拟基金规模与完整持仓权重。ETF 不发行公司财报，进阶布局改为显示「成分与权重」。

- 未解锁板块会在「股票市场」页显示锁定说明、包含的股票代码与解锁条件。
- 解锁后，公司立即出现在市场列表、行情条与交易标的下拉框。
- 直接访问未解锁股票的链接会显示锁定页，应用层也会拒绝该股票的下单请求。
- 这不是真实纳斯达克行情。真实纳斯达克有数千家公司，离线且价格准确不现实；用真实公司名搭配虚构价格也会违背「虚构市场、避免与真实平台混淆」的原则。本项目选择扩大虚构市场并做分阶段解锁，保留可验证的教学边界。

- 历史页使用游戏默认时间系统：每个交易日 **8 个 tick**，支持暂停 / 继续、`1× / 5× / 20×` 速度与推进到下一交易日；每 tick 价格、权益与持仓都会更新。
- 每个日线 OHLC 被确定性地展开为开盘 → 最高 / 最低 → 收盘的日内路径，因此 K 线与成交价会在一天内持续变化，同时仍尊重真实日线高低点。
- 逐日快速跳转仍保留：`+1 / +5 / +20 日`，或跳到下一历史事件；页面顶部有历史时间轴与进度条。
- 进入场景时自动载入前 20 个交易日作为观察窗，因此一开始就能看到多根真实 K 线与成交量柱，而不是只有一天。
- 个股图表支持 **5分 / 15分 / 1时 / 日K / 周K / 月K / 年K** 七种周期切换，均为复权蜡烛图 + 成交量柱。
- 日 / 周 / 月 / 年 K 由真实复权日线聚合；5分 / 15分 / 1时 K 由真实日线 OHLC **确定性展开为模拟盘中路径**，不是真实分钟行情，界面会明确标注。
- 图表只显示当前日期及之前的数据；默认展示全部已发生周期，不会看到未来。
- 独立虚拟账户 $10,000；以当前 tick 的**复权价格**成交，每笔 $1 佣金；QQQ 仅作为基准，不可交易。
- 2020 / 2022 场景可按板块筛选、搜索代码，再选择标的查看走势与下单。
- 图表、行情与事件只显示当前日期及之前的数据，避免看到未来。
- 真实历史事件时间线：雷曼破产、TARP、疫情熔断、加息周期、硅谷银行等。
- 进度单独保存，不会改变学院账户、订单或课程成绩。

### 数据来源与边界

- 价格来自 **Yahoo Finance chart API 的构建时快照**，按拆股与股息复权；成交量未复权。
- 数据仅供本地教学，不是实时行情，也不是官方交易所授权数据源。
- 纳斯达克与纽交所混合：科技、软件、生物科技、医疗、金融、消费以纳斯达克为主；工业、能源、公用事业、房地产包含大量纽交所龙头，界面会标注 NASDAQ / NYSE。
- 2015–2026 场景已扩展到 75 个代码，覆盖科技、医疗、工业、能源、公用事业与通信。
- 不是完整 3,000+ 纳斯达克；只有日线收盘价，没有分钟数据、盘口或做空/期权。
- 存在幸存者偏差：只包含仍在交易的公司，不含退市或破产归零的公司。
- 重新抓取数据（需要联网）：

```bash
python3 tools/fetch-history.py all
python3 tools/build-offline.py
```

离线单文件版会把四套历史数据一起内联，体积约 15 MB。

## 已实现功能（Phase 1–8 完成）

- **第一阶段 4 个完整单元**：股票、交易流程、盈亏计算、订单基础。
- **首次启动引导**：选择中文或英文，创建游戏后直接进入第一课；重置进度会重新回到该引导。
- **教学闭环**：阅读讲解 → 拖动互动演示 → 真实操作验证 → 单元测验 → 逐步解锁。
- **中英双语**：全部界面、课程、题目、解析、新闻、术语与风险提示均来自 `locales/*.json`；切换语言不会重置课程、账户或订单。

- **Sandbox Mode**：独立存档与账户，可自定义起始资金（$1,000–$10,000,000）、市场种子与难度（佣金 0 / 1 / 3）；课程解锁从职业存档复制，沙盒交易不会写回职业账户，可随时退出或重开。
- **Challenge Mode**：6 个目标驱动挑战（收益、回撤、对冲、期权收入、波动率、全能交易），按启动时的权益与交易序号计算，含倒计时、实时进度、完成 XP 与超时/重试。
- **Career Mode**：8 级职业晋升（个人投资者 → 独立交易员 → 研究分析师 → 量化分析师 → 组合经理 → 对冲基金经理 → 基金创始人 → 金融集团 CEO）。每一级都按真实学习进度、交易记录、实验、挑战、专业分支、账户权益、投资报告与绩效评价评估晋升条件；每 21 个交易日发放一次薪资并计入职业收入，晋升额外奖励 XP，不重置账户或课程。职业页提供研究任务板、投资报告评分（观点 / 信心 / 目标价 / 摘要综合打分）、每 21 个交易日的绩效评价（收益、回撤、报告完成度）与 5 类真实职业证书；仪表盘同步展示已获得与待结算证书。沙盒模式不发放薪资，晋升只写入沙盒存档。
- **基金经营**：达到职业等级 5 后可在 `/fund` 成立自己的基金。基金拥有独立账户、客户份额与单位净值；可选择纯多头 / 宏观 / 量化 / 市场中性策略、保守 / 均衡 / 进取风险偏好与三档初始 AUM。成立时可选择市场指数 / MKT 宽基 ETF / 现金作为业绩基准，设置 0% / 2% / 4% 年化业绩门槛，并决定是否启用风险偏好对应的 1.00x / 1.25x / 1.50x 杠杆。客户按单位净值申购与赎回，管理费每 21 个交易日按年费率折算计提，业绩报酬需同时超过高水位与门槛；可聘请研究员、量化、风控、交易员、宏观、运营与合规官。客户有明确的预期年化收益，未达标会降低信任度并提高赎回概率；运营成本每月从管理公司现金计提。基金受单票仓位上限、现金 / 杠杆下限与 40% 回撤清盘线约束，并会因流动性、欠薪导致关键人员离职、连续风险触线（无合规官时更早）、杠杆失控或客户全部赎回而清盘；清盘后可直接重新成立基金。新增策略计划：用 5 个量化策略之一生成再平衡建议（目标持仓数、现金缓冲、参数可调），执行时仍走仓位 / 现金 / 杠杆校验；收益归因拆分为市场 Beta、板块偏离、现金拖累、费用与选股残差，并展示板块暴露。基金排行榜与同类模拟基金比较累计收益。
- **量化实验室**：完成第 16 单元后解锁 `/quant`。独立于交易账户，提供 5 个预设策略（买入持有、均线交叉、RSI 均值回归、动量、区间突破）、可调参数、初始资金与佣金设置；信号在收盘确认、下一开盘成交，输出累计 / 年化收益、最大回撤、夏普比率、胜率、持仓时间、买入持有对照、权益曲线与交易记录。三种研究模式：（1）单策略回测；（2）参数网格优化，按夏普 / 收益 / 年化 / Calmar 选择样本内最优组合，并用样本外数据检验过拟合；（3）横截面逻辑回归选股，用动量、低波动与趋势特征训练模型，输出样本外准确率、因子权重、选股组合曲线与命中率。因子研究支持动量、低波动、趋势与估值四类排序，观察窗口可调。

## 操作指南

- **市场时钟**（顶部）：暂停 / 继续、1× / 5× / 20× 速度、快进到下一交易日。暂停时行情冻结，订单不会撮合。
- **语言**：右上角按钮即时切换 `中文 ⇄ EN`，金额始终为虚拟美元，不做货币换算。
- **职业模式**：Career 页面显示当前职级、下一职级条件、薪资倒计时与职业收入。晋升条件直接读取课程、交易、实验、挑战、分支、权益、XP、投资报告与绩效评价，满足后点击晋升；薪资每 21 个交易日自动到账。晋升到独立交易员后可接取研究任务，填写观点、信心、目标价与摘要提交报告；评分达到 60 分才计入职业进度，并在每 21 个交易日获得一次绩效评价。
- **学习流程**：Academy → 单元 → 章节。点击「标记已学完并继续」才会记录进度；测验达到 80% 通过。已有基础可使用「跳级测试」（达到 90% 跳过课程与实战任务）。
- **实战任务**：系统直接检查模拟账户中的真实操作（例如买入金额、限价单成交、查看两家公司市值），没有「直接完成任务」按钮。
- **板块解锁**：完成单元的全部要求（阅读、实战、测验）后自动解锁对应板块，并提示新增可交易公司。
- **交易**：Market → 选择公司 → Trading 页面下单。默认每笔成交收取 $1.00 虚拟佣金；买入手续费计入持仓成本，卖出时按平均成本计算已实现盈亏。
- **做空与保证金**：完成 Unit 17 第一节后解锁「做空 / 平空」，卖空需 50% 抵押；完成 Unit 18 第一节后解锁融资买入（最多 1.5:1 杠杆），融资余额按 8% 年利率每日计息，权益低于维持保证金会被强制平仓。
- **止损 / 追踪止损 / 止损限价 / OCO**：完成 Unit 19 第一节后解锁。止损单在触发价被触及后转为市价单，追踪止损会随有利价格收紧；止损限价单触发后只在限价或更优价格成交，OCO 同时挂出止盈与止损、一腿成交另一腿自动取消。触发后成交价可能滑点。
- **订单簿**：进阶布局在 Unit 20 第一节后显示五档深度与当前数量的滑点估算。
- **期权**：完成 Unit 21 第一节后解锁。期权页提供 30 / 60 / 90 天、7 档行权价的 Call / Put 链，按 Black-Scholes 定价；可买入、卖出开仓、按模型价值平仓，或持有至到期现金结算。
- **期权策略**：Unit 25 起可切换「卖出开仓」；策略卡片可一键构建 Covered Call、Cash-Secured Put、Bull Call / Bear Put Spread、Long Straddle / Long Strangle，并按担保 / 净支出校验后原子成交。
- **期货**：完成 Unit 29 第一节后解锁。期货页提供 30 / 60 / 90 天单只股票期货，15% 保证金；每日收盘按浮动盈亏进行盯市，到期按现货价格现金结算。
- **基金经营**：职业等级 5 后进入 Fund 页成立基金，选择策略、风险偏好、初始 AUM、业绩基准、业绩门槛与是否启用杠杆。基金用独立账户与客户份额运行：在交易区按单位净值买卖标的，客户申购会增加份额与现金、赎回会减少份额并支付现金；每 21 个交易日计提管理费与「高水位 + 门槛」业绩报酬，每 30 个交易日可能出现新客户。可招聘 / 解雇员工来获得研究观点、降低交易费用、加快信任度增长或由合规官降低清盘风险，并随时把管理公司现金提现。单票仓位、现金 / 杠杆下限、客户预期收益、运营成本、关键人员稳定性与 40% 回撤都会影响风控与清盘；清盘后可重新成立基金。
- **量化实验室**：完成 Unit 16 后进入 Quant Lab，选择标的、策略、参数、初始资金与佣金运行回测。结果不会改变模拟账户；策略信号在收盘确认、下一开盘成交，并输出收益、回撤、夏普、胜率、持仓时间、买入持有对照、权益曲线与交易记录。因子研究可按动量、低波动、趋势或估值排序，观察窗口可调。
- **Beginner / Advanced**：新手布局隐藏详细财务数据并显示解释；高级布局显示价差、预留现金、P/E、EPS 等资料。
- **存档**：自动保存；设置页可立即保存、导出 / 导入 JSON 存档、重置进度。

## 关键规则

- 市值 = 股价 × 总股本；收益率 = 盈亏 ÷ 投入成本 × 100%。
- 买入：现金减少（成交金额 + 佣金），成本基础包含佣金。
- 卖出：现金增加（成交金额 − 佣金），已实现盈亏 = 净收入 − 对应成本。
- 市价买 / 卖分别以卖价 / 买价成交；限价单只在价格达到或优于限价时成交，未成交资金 / 股份会被预留。
- 期权、做空、保证金与期货均使用独立的模拟引擎；保证金规则、现金结算与提前指派边界在各自页面和 `/boundaries` 中说明，不连接真实交易所。
